# Cryptocurrency Icons

The SVG icons in this directory are vendored from [spothq/cryptocurrency-icons](https://github.com/spothq/cryptocurrency-icons).

## License
- **License:** Creative Commons Zero v1.0 Universal (CC0-1.0)
- **Upstream Repository:** https://github.com/spothq/cryptocurrency-icons
- **Usage:** Vendored locally to prevent hotlinking and external network dependencies.

## Assets Included
- `btc.svg`: Bitcoin color SVG icon (CC0-1.0).
- `eth.svg`: Ethereum color SVG icon (CC0-1.0).
- `sui.svg`: SUI coin badge is rendered programmatically via the `CoinLogo.tsx` component as a colored badge with ticker text, avoiding trademark redraws as SUI is not present in the upstream CC0 icon set.
